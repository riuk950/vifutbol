# Implementation Plan: Panel Técnico del Entrenador — Listado, Edición y Eliminación de Equipos

**Branch**: `064-coach-panel-teams-crud` | **Date**: 2026-11-26 | **Spec**: [spec.md](file:///Volumes/DATA/Development/FlutterProjects/vifutbol/specs/064-coach-panel-teams-crud/spec.md)

**Input**: Feature specification from `/specs/064-coach-panel-teams-crud/spec.md`

## Summary

Extender el **Panel Técnico del Entrenador** (`CoachPanelContent`) para listar **todos** los equipos creados por el entrenador autenticado (`team.coachId == currentUser.id`, eliminando el fallback implícito a `coach-seed-1` cuando hay sesión activa), permitir seleccionar cualquiera de ellos para actualizar reactivamente métricas, próximo partido, acciones rápidas y plantilla por posición, y habilitar acciones explícitas de **Editar** (reutilizando `CreateTeamScreen` en modo edición con `initialTeam`) y **Eliminar** (con diálogo de confirmación en español, bloqueo cuando participa en torneos en curso/finalizados o tiene partidos registrados, validación de propietario y borrado offline-first local + Supabase).

## Technical Context

**Language/Version**: Dart 3.x / Flutter SDK (project SDK constraint)  
**Primary Dependencies**: `flutter_riverpod`, `fluro`, `supabase_flutter`, `hive_flutter`, `image_picker`, `uuid`  
**Storage**: Local offline-first (`LocalTeamsRepository` + `SyncOutbox`) + Supabase PostgreSQL (`vifutboldev.teams`, `vifutboldev.tournament_teams`) & Storage (`team-crests`)  
**Testing**: `flutter test` (unit + widget tests) & `flutter analyze`  
**Target Platform**: iOS & Android mobile (Flutter)  
**Project Type**: Mobile application (Clean Architecture: `domain` / `application` / `infrastructure` / `presentation`)  
**Performance Goals**: Actualización inmediata (<1s) del Panel Técnico al seleccionar, editar o eliminar un equipo; interfaz receptiva sin bloquear UI durante operaciones de red.  
**Constraints**: Offline-first con outbox (`SyncOutboxEntityType.team`), bloqueo `single-flight` en guardado y eliminación, áreas táctiles ≥ 48×48 dp, 100% textos en español vía `AppLocalizations` (`lib/l10n/app_es.arb`), código y tests en inglés.  
**Scale/Scope**: Equipos por entrenador (típicamente 1–20 clubes), 3 pantallas/componentes principales (`CoachPanelContent`, `CreateTeamScreen`, `AppRouter`) + capa de aplicación/infraestructura (`teams_providers`, `TeamsController`, `ManageTeamsEligibilityUseCase`, `HybridTeamsRepository`).
